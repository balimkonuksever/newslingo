# CEFR sentence classifier against a zero-shot LLM, 2026-11-25

Written by `python -I -m newslingo_ml.zero_shot`. Do not edit by hand; rerun it.

## Setup

- Data: CEFR-SP, Wiki-Auto subset, revision `2ba4a5005fbff68ab0f863891cf977c50fdcda29`, CC BY-SA 3.0, all 762 sentences of the test split. Card: `ml/datasets/cefr-sp.md`. Gold level and metrics as in the earlier reports; the paper's macro-F1 is the metric of Arase et al. (2022).
- Zero-shot LLM: `claude-opus-5-5` at high effort, through Claude Code headless (`claude -p`, version 2.1.332) on the user's Claude plan. Every call's session ran on `claude-opus-5-5`; Claude Code also made small calls of its own to `claude-haiku-5-5`, counted below.
- The sentences went in an order fixed by the seed, in batches of 20, detokenized and numbered, with the system prompt `ml/prompts/cefr-zero-shot-v1.txt` (version v1, SHA-256 `48d8364dce438fb5…`) and a JSON schema that allows one of the six levels for each. The prompt gives the CEFR-SP annotators' definition (a sentence's level is the lowest at which a learner readily understands it), short descriptions of the levels and the annotators' rule not to judge by the words alone, and asks for each sentence to be rated on its own. It shows no labelled example, where the annotators' guidelines had some. Claude Code ran with no tools, settings, MCP servers or skills, from an empty folder. Batches keep the whole split within the limits of the user's Pro plan.
- The prompt and settings were fixed before the test split was sent, after a pilot on 40 validation sentences. The model cannot be made deterministic through Claude Code, so a rerun of the calls can give other answers; this report is reproducible from the answers recorded in `ml/reports/zero-shot-test-claude-opus-5-5-high-prompt-v1-batch-20.jsonl`.
- Classifier: average of 4 runs (3 × distilroberta-base, 1 × FacebookAI/roberta-base), read as its most likely level, from `reports/2026-11-19-ensemble-dev-all-four.json`, chosen on the validation split on 2026-11-19.
- The light model is the one `newslingo_ml.sentence_eval` chooses: ridge (smoothing 2, alpha 10).
- The classifier, the light model and the baselines score exactly as they did in `reports/2026-11-19-transformer.json` on the same test sentences.
- CEFR-SP has been public since 2022, so the LLM may have seen its labels in training, which would favour it.
- This report's code is at `cb466f7fcac3e1a86176ca407627c42e76139730`. Intervals are 95% bootstrap intervals over test sentences (1,000 resamples).

## Validation pilot

Before the test split, the same prompt and settings rated 40 validation sentences, the first batches in the seeded order (`ml/reports/zero-shot-dev-claude-opus-5-5-high-prompt-v1-batch-20.jsonl`). The LLM matched an annotator on 67.5% of them, exactly on 52.5%, with a QWK of 0.695. Nothing was tuned on the test split.
